# 线程池使用说明文档

## 概述

本项目中集成了完整的线程池使用示例，展示了在Spring Boot应用中如何正确配置和使用线程池来提高应用性能。

## 线程池配置

### 1. 线程池类型

项目中配置了三种不同用途的线程池：

- **asyncTaskExecutor**: 通用异步任务线程池
  - 核心线程数：CPU核心数
  - 最大线程数：CPU核心数 × 2
  - 队列容量：200
  - 适用场景：通用异步任务处理

- **emailTaskExecutor**: 邮件发送专用线程池
  - 核心线程数：5
  - 最大线程数：10
  - 队列容量：100
  - 适用场景：IO密集型任务（如邮件发送、文件上传等）

- **dataProcessExecutor**: 数据处理专用线程池
  - 核心线程数：CPU核心数
  - 最大线程数：CPU核心数
  - 队列容量：50
  - 适用场景：CPU密集型任务（如数据统计、报表生成等）

### 2. 配置文件位置

`src/main/java/com/marine/manage/config/ThreadPoolConfig.java`

## 代码实现要点

### 1. 异步方法注解

```java
@Async("asyncTaskExecutor")
public CompletableFuture<String> asyncMethod() {
    // 异步处理逻辑
    return CompletableFuture.completedFuture("结果");
}
```

### 2. 等待异步结果

```java
CompletableFuture<String> future = asyncService.asyncMethod();
try {
    // 等待最多5秒
    String result = future.get(5, TimeUnit.SECONDS);
} catch (TimeoutException e) {
    // 处理超时
}
```

### 3. 并发执行多个任务

```java
CompletableFuture<String> task1 = asyncService.task1();
CompletableFuture<String> task2 = asyncService.task2();
CompletableFuture<String> task3 = asyncService.task3();

// 等待所有任务完成
CompletableFuture<Void> allTasks = CompletableFuture.allOf(task1, task2, task3);
allTasks.get(15, TimeUnit.SECONDS);
```

## 性能优化建议

### 1. 选择合适的线程池

- **CPU密集型任务**: 使用 `dataProcessExecutor`
- **IO密集型任务**: 使用 `emailTaskExecutor`
- **通用异步任务**: 使用 `asyncTaskExecutor`

### 2. 监控线程池状态

定期检查线程池的使用情况：
- 活跃线程数
- 队列大小
- 完成任务数
- 负载百分比

### 3. 避免线程池滥用

- 不要为短时间的简单操作使用线程池
- 避免在线程池中执行阻塞操作
- 合理设置超时时间

## 注意事项

1. **事务处理**: 异步方法中的事务与调用方法的事务是独立的
2. **异常处理**: 异步方法中的异常不会传播到调用方，需要通过返回值处理
3. **内存管理**: 长时间运行的异步任务需要注意内存使用
4. **优雅关闭**: 应用关闭时会等待正在执行的任务完成

## 测试建议

1. **负载测试**: 使用JMeter等工具测试并发性能
2. **监控测试**: 观察线程池在高负载下的表现
3. **异常测试**: 测试异步任务失败时的处理机制
